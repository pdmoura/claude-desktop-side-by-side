# Code of Conduct

This project is a small, friendly space. Everyone who takes part (in issues, pull requests or discussions) is expected to:

- **Be respectful.** Disagree with ideas, not people. No harassment, insults, or discriminatory language.
- **Be helpful.** Assume good intent, explain your reasoning, and remember many contributors are doing this in their free time.
- **Stay on topic.** Keep discussions about this project. Problems with Claude Desktop itself belong with Anthropic support.
- **Respect privacy.** Don't post other people's personal information, and redact your own tokens, emails and file paths in logs.

The maintainer may edit, hide or remove comments, issues and pull requests that break these rules, and may block repeat offenders.

To report a problem privately, contact the maintainer through their [GitHub profile](https://github.com/pdmoura).
